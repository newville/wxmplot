Installation
====================================

.. _github:   https://github.com/newville/wxmplot
.. _PyPI:     https://pypi.python.org/pypi/wxmplot


Prerequisites
~~~~~~~~~~~~~~~

The current version of wxmplot is |release|, released in August, 2026

The wxmplot package requires Python 3.11 or higher, wxPython 4.2.3 or
higher, matplotlib 3.9.0 or higher, numpy 2.0 or higher, and Pillow
7.0 or higher, pyopengl 3.1.10, and vispy 0.16.2 or higher.  All of these are readily
available from `pip` or on `conda` channels.



Installation
~~~~~~~~~~~~~~

The latest version (|release|) is available from `PyPI`_ or `github`_, and
the package can be installed with::

   pip install wxmplot


Development Version
~~~~~~~~~~~~~~~~~~~~~~~~

To get the latest development version, use::

   git clone https://github.com/newville/wxmplot.git

Installation from Source
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

wxmplot is a pure python module, so installation on all platforms can use
the source kit and a standard installation using::

   pip install .
